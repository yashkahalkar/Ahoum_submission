# 🤖 RAG-Based Conversational Facet Scorer

This project implements a sophisticated RAG (Retrieval-Augmented Generation) system to score conversational turns against over 300 distinct behavioral facets. It leverages a powerful generative model (Google's Gemini) for high-quality dataset creation and a fast, local LLM (Phi-3) for real-time, context-aware scoring.

---

## ✨ Features

- **High-Quality Dataset:** The foundation of the project is a rich dataset of conversational facets, definitions, and scoring rubrics generated by the Gemini API.
- **Vectorized Knowledge Base:** Facet definitions are stored in a [Pinecone](https://www.pinecone.io/) serverless vector index for efficient, semantic retrieval.
- **Local-First Inference:** Real-time scoring is handled by a local `phi3` model running via [Ollama](https://ollama.com/), ensuring privacy and low latency.
- **Interactive UI:** A user-friendly web interface built with [Streamlit](https://streamlit.io/) allows for easy interaction and testing.
- **Modern RAG Orchestration:** The entire workflow is managed by the [LangChain](https://www.langchain.com/) framework.

---

## ⚙️ Tech Stack

- **Backend:** Python
- **Orchestration:** LangChain
- **Vector Database:** Pinecone
- **Data Generation LLM:** Google Gemini
- **Local Inference LLM:** Ollama (running Phi-3)
- **Frontend:** Streamlit

---

## 🏗️ Project Architecture

The project operates in two main phases: a one-time indexing step and a real-time scoring application.

1.  **Indexing (Setup):**
    - The `1_index_data_to_pinecone.py` script reads the `fully_automated_dataset.csv`.
    - It takes the unique facet definitions/rubrics (the `context` column).
    - These contexts are converted into vector embeddings using a local embedding model (`nomic-embed-text`).
    - The documents and their embeddings are uploaded and stored in a Pinecone vector index.

2.  **Scoring (Application):**
    - The Streamlit `app.py` launches a web interface.
    - A user enters a **Facet Name** and a **Conversation Turn**.
    - The application uses the Facet Name to retrieve the most relevant rubric from the Pinecone index.
    - This retrieved rubric (context) is combined with the Conversation Turn into a detailed prompt.
    - The complete prompt is sent to the local `phi3` model via Ollama.
    - The model returns a score from 1-5, which is then displayed in the UI.

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### 1. Prerequisites

- Python 3.9+
- An account with [Pinecone](https://www.pinecone.io/) to get a free API key.
- [Ollama](https://ollama.com/) installed and running on your machine.

### 2. Installation and Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    cd your-repo-name
    ```

2.  **Create a virtual environment and install dependencies:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    pip install -r requirements.txt
    ```

3.  **Set up API Keys:**
    - Create a folder named `.streamlit` in your project directory.
    - Inside that folder, create a file named `secrets.toml`.
    - Add your keys to this file:
      ```toml
      # .streamlit/secrets.toml
      PINECONE_API_KEY = "your_pinecone_api_key_here"
      ```

4.  **Download Ollama Models:**
    - Open your terminal and pull the necessary models for the application:
      ```bash
      ollama pull phi3
      ollama pull nomic-embed-text
      ```

### 3. Usage

1.  **Populate the Knowledge Base (Run Once):**
    - Execute the indexing script to upload your facet data to Pinecone.
      ```bash
      python 1_index_data_to_pinecone.py
      ```

2.  **Launch the Application:**
    - Start the Streamlit web server.
      ```bash
      streamlit run app.py
      ```
    - Open your web browser to the local URL provided by Streamlit.
